# 刷题记录（shuati）

一个自用的刷题记录 App（PWA），天蓝毛玻璃风格，适配 iPhone。

## 功能

- 📝 记录每日刷题的类型、数量、第几遍，支持自由切换日期查看某天记录
- 📊 统计当日 / 本月 / 本月日均 / 连续打卡天数，近 7 天 / 30 天趋势图
- 🗂️ 模块管理：给一套题目逐遍记录正确率、错题数，标记全刷完
- 📕 错题本：记录错题编号、知识点，支持导入题目图片
- 🎯 每日目标与进度、数据导出 / 导入备份

## 使用

数据保存在浏览器本地（localStorage），**不会上传到任何服务器**。

在 iPhone 的 Safari 打开本页面 → 底部「分享」→「添加到主屏幕」，即可像原生 App 一样全屏使用。

## 技术

纯 HTML / CSS / JS 单文件，无需构建。
